# Security Policy

## Scope

The High-Security Facility Concept is a conceptual documentation project.
It does not provide production software, operational security services,
certified facility designs, or deployment-ready security controls.

Security concerns may still relate to:

- exposed credentials or secrets
- repository access
- compromised dependencies or files
- malicious changes
- privacy-sensitive material
- unsafe operational guidance
- accidental disclosure of confidential facility information
- misleading claims about security or life-safety behavior

## Reporting a Concern

Please do not publish sensitive information in a public issue.

For suspected security vulnerabilities, exposed credentials, private
information, or malicious repository activity, contact the repository
maintainer privately through the GitHub security contact method or the
maintainer’s verified contact channel.

Include:

- a clear description of the concern
- the affected file or repository area
- steps to reproduce, where applicable
- potential impact
- suggested remediation, if known
- whether public disclosure has already occurred

Do not include:

- real facility layouts
- access credentials
- private operational procedures
- personal data
- live security-system information
- confidential client information
- weapon or intrusion instructions

## Response Process

Reports will be reviewed and classified according to:

- confidentiality impact
- integrity impact
- safety implications
- exploitability
- repository or documentation scope
- need for immediate mitigation

The maintainer may:

- acknowledge the report
- request clarification
- remove exposed information
- rotate compromised credentials
- correct unsafe documentation
- publish a corrective update
- coordinate responsible disclosure

## Conceptual-Project Limitation

The documents in this repository are conceptual and must not be treated
as a substitute for:

- certified security engineering
- professional risk assessment
- legal review
- life-safety engineering
- facility-specific threat analysis
- emergency planning
- qualified incident command
- tested operational procedures

## Supported Versions

Only the latest version on the default branch is actively maintained.

Older releases are historical snapshots and may contain outdated
terminology, assumptions, or design material.
